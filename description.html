AI Simulation button for TinyMCE

Insert interactive machine learning simulations into any Moodle text, without writing HTML.

Live demo: try the plugins on aisim.tsp.edu.rs. Log in as a guest, or use the demo accounts teacher (to try this editor button) and student, password Demo-2026. Everything is reset every night. The simulations alone, without Moodle: sim.aiforvet.eu.

What's new in 0.13.0

  • Data preparation: insert the new simulation with its dataset, k and the starting pipeline for missing values, outliers and scaling.

Features

  • Button and menu item: an AI Simulation button in the editor toolbar and an entry in the Insert menu, in every editor on the site.
  • Twelve simulations: gradient descent, confusion matrix, polynomial regression, k-NN and decision tree, k-means, perceptron and neural network, convolution (image filters), Q-learning, data split and bias, logistic regression, cross-validation, and data preparation.
  • Settings in a dialog: the scenario or dataset and the starting values of each simulation, such as the threshold, learning rate, polynomial degree, k, tree depth, hidden layers, kernel or exploration rate, with a live preview.
  • Edit again: double-click an inserted simulation to open the dialog with its current settings.
  • Read-only mode: lock the controls when a simulation only shows a fixed example in a lecture.
  • Safe in the text: the simulation is a protected card in the editor, so typing around it cannot break its settings.
  • Translatable: all texts are language strings and can be translated in AMOS.

The AI simulation plugins

  • AI Simulations Viewer (filter_aisim): runs the simulations in any content; required.
  • AI Simulation button for TinyMCE (this plugin): inserts and edits the simulations in the editor.
  • AI Simulation question type (qtype_aisim): quiz questions solved inside a simulation and graded automatically.

Requirements

  • Moodle: 4.5 LTS to 5.3, with the TinyMCE editor.
  • filter_aisim: installed and enabled, so that the inserted simulations run for readers.

Privacy

The plugin stores no personal data and sends nothing to external services; it implements the Moodle Privacy API. The simulation settings are saved in the text as data attributes.

About

Developed in the Erasmus+ project AI for VET for vocational schools. A teacher guide in English, Serbian, Slovak and Portuguese is in the GitHub repository. Source code, issues and the changelog are there as well.
