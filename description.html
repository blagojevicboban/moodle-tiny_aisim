Tiny AI Simulation (tiny_aisim) Visual Editor Plugin

Seamlessly insert and configure interactive AI and Machine Learning simulation cards in Moodle course content using TinyMCE 6 and TinyMCE 7.

Key Features

  • Visual Integration: Adds an AI Simulation button to the TinyMCE editor toolbar and an entry in the Insert menu.
  • Modal Configuration Dialog: Easy selection of simulation types (Gradient Descent, Confusion Matrix, Polynomial Regression, Decision Boundaries, K-Means) with dynamic parameter inputs.
  • Double-Click In-Place Editing: Simply double-click any existing simulation placeholder in the editor to re-open the configuration dialog with loaded values.
  • Read-Only Protection: Option to lock simulation controls for students, ideal for guided theory lectures.
  • Non-Destructive Cards: Safe contenteditable="false" cards protect metadata from accidental edits while typing surrounding lesson text.
  • Multilingual Support: English, Serbian Latin, and Serbian Cyrillic.

Compatibility

  • Compatible with Moodle 4.5 LTS, 5.0, 5.1, 5.2, and 5.3+.
  • TinyMCE 6 / TinyMCE 7 editor.
  • Requires filter_aisim.
